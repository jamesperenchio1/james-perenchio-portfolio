## Overview

This was a one-day hackathon build: a small Python machine learning prototype for electricity
trading that predicts demand and price movements. The aim was a working proof of concept that
could read market signals and make a better call on when to buy or sell.

## Working to a one-day deadline

I'm keeping this write-up short because the project was short: one day, start to finish.
Hackathons reward getting something working over polish. The job is to take a real problem,
cut it down to something you can get running in a few hours, and have it working before the
deadline.

I've included it because that's a skill I use all the time. Electricity trading is a messy,
data-heavy problem, and the day was about narrowing it to a core the model could handle and
getting that running by the end.

## Stack

Python and standard machine learning tooling, used to prototype demand and price prediction
